# **App Name**: Hibo Hub

## Core Features:

- Premium Subscription Management: Implement a hard paywall ('Ku Biir Hibo Premium') blocking core features, offering monthly and yearly pricing tiers with high-converting copy. Allows a single free test generation before requiring subscription.
- AI Music Generation Tool: Utilize the Gemini API and Audio API pipeline to generate songs ('Hees Sameyso') from multi-line text prompts and selected Somali genres (Dhaanto, Qaraami, Afro-Somali, Rap). Features a glowing 'Abuur Hees' (Generate Song) button.
- AI Video & Visualizer Generation Tool: An innovative AI tool ('Muuqaal Sameeye') that generates dynamic music videos or audio visualizers to match created songs, based on prompt inputs for video style (e.g., 'Cinematic, Anime, Realistic'). Activated by a 'Samee Muuqaal' (Generate Video) button.
- AI Voice Cloning Studio Tool: A recording interface ('Codkaaga Sameyso') featuring a large microphone icon and waveform visualizer. Allows users to record a 1-minute voice sample ('Duub Codkaaga') to create a custom AI voice model for their songs.
- User Generated Content Library: A dedicated section ('Kaydkaaga') for storing and organizing all user-created songs, videos, and custom voice models within the Google ecosystem using Firebase for metadata.
- Integrated Media Player: A sleek media player within the Studio Library ('Kaydkaaga') handling both audio and video playback for generated content.
- Content Sharing & Download: Functionality within the Studio Library to download generated media and directly share content to popular social platforms like TikTok and Instagram.

## Style Guidelines:

- Primary brand color: A vibrant, deep purple (#8C2CFB). This rich hue signifies premium creativity and energy, contrasting beautifully in a dark mode setting while echoing the 'neon purple' glow effect.
- Background color: A subtly purple-tinted dark grey (#18151D). This highly desaturated, low-brightness background ensures text and vibrant UI elements stand out in the premium dark mode aesthetic.
- Accent color: An electric, neon blue (#36CDFF). This color provides high contrast against the primary purple and background, embodying the 'neon teal' glow effects for interactive elements and highlights.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, techy, and slightly futuristic appeal, aligning with the advanced AI nature of the app. Body text font: 'Inter' (sans-serif) for exceptional readability across various screen sizes, ensuring clarity for prompts and general information.
- Minimalistic Afrocentric/East African vector art for key branding elements and module icons. Icons should adopt the neon teal/purple glow effects, maintaining clarity in a dark environment, aligning with the overall premium and culturally inspired aesthetic.
- Implement a 'highly premium Dark Mode' with a clean, intuitive layout following Material Design 3 principles. Emphasize spaciousness and visual hierarchy to enhance user experience.
- Subtle yet striking 'neon teal/purple glow effects' on interactive elements (e.g., 'Abuur Hees' button). Dynamic audio visualizers ('Muuqaal Sameeye' module) that synchronize with generated music, adding an immersive and cutting-edge feel.
